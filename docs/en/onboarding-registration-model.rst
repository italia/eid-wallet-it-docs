Registration Model
------------------

This part gives the static view of the registration, with the aim of providing useful information about data that each Entity has to provide, which conditions it has to meet and which artifacts and registry entries it obtains, organized as a common part and a profile for each role.

Registration Profiles
^^^^^^^^^^^^^^^^^^^^^

This section describes the registration of each role as a profile.
Each profile is built looking at the registration in the EUDIW and National Trust Framework, and the notification process, providing only the information that is specific to that role.
An Entity can hold more than one role in a single registration, so the profiles are not mutually exclusive and they can be composed.
