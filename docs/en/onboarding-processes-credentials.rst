Attestation Onboarding
^^^^^^^^^^^^^^^^^^^^^^

This section describes the processes that manage the claims, the schemas and the Credential types.
Each process is described with its Input, its Outcome and its Process.

Claim Registration
""""""""""""""""""

.. note::
   Draft. To be written.

Process that adds a claim to the Claims Registry when a needed claim is not available, and aligns it towards the corresponding European catalog.

Schema Provisioning
"""""""""""""""""""

.. note::
   Draft. To be written.

Process that makes the schema of a Credential type available in the Schema Registry, either by generating it from the data model for nationally defined Credentials, or by registering it in alignment with an external Rulebook or standard.

Credential Type Registration
""""""""""""""""""""""""""""

.. note::
   Draft. To be written.

Process that creates a versioned entry of a Credential type in the Digital Credentials Catalog, with its data source and the reference to the applicable Rulebook.

Credential Type Activation and Deactivation
"""""""""""""""""""""""""""""""""""""""""""

.. note::
   Draft. To be written.

Process that verifies the conditions for the issuance of a Credential type and moves its versioned entry between the active and the inactive state.

Credential Type Update
""""""""""""""""""""""

.. note::
   Draft. To be written.

Process that publishes a new version of a Credential type, activating the new versioned entry and deactivating the previous one.
