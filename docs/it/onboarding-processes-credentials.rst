Attestation Onboarding
^^^^^^^^^^^^^^^^^^^^^^

Questa sezione descrive i processi che gestiscono claim, schema e Credential types.
Ciascun processo è descritto con il proprio Input, il proprio Outcome e il proprio Process.

Claim Registration
""""""""""""""""""

.. note::
   Draft. To be written.

Processo che aggiunge un claim al Claims Registry quando un claim necessario non è disponibile, e lo allinea verso il catalogo europeo corrispondente.

Schema Provisioning
"""""""""""""""""""

.. note::
   Draft. To be written.

Processo che rende disponibile lo schema di un Credential type nello Schema Registry, generandolo dal data model per le Credential definite a livello nazionale, oppure registrandolo in allineamento con un Rulebook o uno standard esterno.

Credential Type Registration
""""""""""""""""""""""""""""

.. note::
   Draft. To be written.

Processo che crea una voce versionata di un Credential type nel Digital Credentials Catalog, con la propria data source e il riferimento all'Attestation Rulebook applicabile.

Credential Type Activation and Deactivation
"""""""""""""""""""""""""""""""""""""""""""

.. note::
   Draft. To be written.

Processo che verifica le condizioni per l'emissione di un Credential type e sposta la sua voce versionata tra lo stato active e inactive.

Credential Type Update
""""""""""""""""""""""

.. note::
   Draft. To be written.

Processo che pubblica una nuova versione di un Credential type, attivando la nuova voce versionata e disattivando la precedente.
